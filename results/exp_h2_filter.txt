
=== Experiment 4: the H2 fingerprint ablation ===================
Three tables with the same layout, the same probe order and the same
load factor, differing only in what the control byte carries.

The theoretical false-positive rate of a 7-bit fingerprint is 1/128 =
0.78% per occupied slot examined. The first row should land near it; the
third should not, despite storing exactly the same 7 bits.

Timing noise on this run: worst (max-min)/min across all measurements was 237.6%.
That is high. Timings below are best-of-7 and still carry that much run-to-run
variation, so read the counter columns as the result and the nanoseconds as
corroboration. See RESULTS.md for this machine's configuration.
